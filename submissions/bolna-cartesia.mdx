## Overview

[Bolna](https://www.bolna.ai/docs/introduction) runs voice AI agents over the phone, chaining a speech-to-text (STT) transcriber, an LLM, and a text-to-speech (TTS) synthesizer on each call. Set [Sonic](/build-with-cartesia/tts-models/latest) as the agent's synthesizer to speak every reply with a Cartesia voice.

## Prerequisites

- A Bolna account at [platform.bolna.ai](https://platform.bolna.ai) with wallet credits, since calls consume credits
- A Bolna API key (`BOLNA_API_KEY`) from [Generate an API key](https://www.bolna.ai/docs/api-reference/introduction)
- A phone number to call, in [E.164](https://en.wikipedia.org/wiki/E.164) format (for example `+919876543210`)
- A [Cartesia API key](https://play.cartesia.ai/keys) (looks like `sk_car_...`). If you'd rather use the Cartesia usage included with your Bolna account, you can skip this
- One of: `curl`; Python 3.9+ with `requests` (`pip install requests`); or Node.js 18+ for the TypeScript examples, which run with `npx tsx`

## Quick start

<Steps>
  <Step title="Connect your Cartesia API key" titleSize="h3">
    In the Bolna dashboard, open **Settings** > [**Integrations**](https://platform.bolna.ai/providers), filter by **TTS**, click **Connect** on the **Cartesia** card, and paste your Cartesia API key. If you'd rather use the Cartesia usage included with your Bolna account, you can skip this step.
  </Step>

  <Step title="Set environment variables" titleSize="h3">
    ```bash
    export BOLNA_API_KEY="bn-your-key"
    ```

## Configuration

Cartesia settings live in `tools_config.synthesizer.provider_config`:

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `model` | `string` | Required | `sonic-3.6`, `sonic-3.5`, or `sonic-3` |
| `voice` | `string` | Required | Voice display name, for example `"Brooke - Big Sister"` |
| `voice_id` | `string` | Required | Voice ID from Bolna's voice catalog (see below) |
| `language` | `string` | Required | Language code for synthesis, for example `"en"` or `"hi"` |
| `speed` | `number` | `1` | Speaking rate, from `0.6` to `1.5` |
| `volume` | `number` | `1` | Output volume, from `0.5` to `2` |

Bolna validates `model` and `voice_id` together, so resolve a valid pair with [List TTS providers](https://www.bolna.ai/docs/api-reference/voice/get_providers) and [List voices](https://www.bolna.ai/docs/api-reference/voice/get_all) before you create the agent. For tips on picking a voice, see [Choosing a voice](/build-with-cartesia/capability-guides/choosing-a-voice).
